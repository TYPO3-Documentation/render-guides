Link text in a command's help 

A command's help comes from the JSON the command writes, not from the manual, so a link there without a text of its own is not reported:

cache:warmup

cache:warmup
Warmup TYPO3 caches.
Usage
cache:warmup
Copied!
Help

This command is useful for deployments to warmup caches.
