===============
Example vendors
===============

The setting names the namespaces this manual invents. Here that is
:php:`\Acme\Shop\Service\Greeter` and :php:`\OriginalVendor\Ext\Thing`, which
the index passes over, while :php:`\MyVendor\MyExtension\FooBar` is a class of
this manual's own and is indexed:

..  code-block:: php

    <?php
    use Acme\Shop\Service\Greeter;
    use OriginalVendor\Ext\Thing;
    use MyVendor\MyExtension\FooBar;
