PHP namespaces 

A namespace named explicitly: \TYPO3\CMS\Core\Utility , also without the leading backslash: \TYPO3\CMS\Core .

A namespace the API knows, named with a class role, is a namespace too: \TYPO3\CMS\Core\Utility , \TYPO3\CMS\Core\Utility .

A class stays a class: \TYPO3\CMS\Core\Utility\GeneralUtility .

A name that is both a class and a namespace is the class with :php: and the namespace with :php-namespace:: \TYPO3\CMS\Core\Exception , \TYPO3\CMS\Core\Exception .

An example namespace: \MyVendor\MyExtension\Controller .

A namespace the API does not know: \Symfony\Component\Console .

A use statement that imports a namespace does not make it a class either:

<?php

use TYPO3\CMS\Extbase\Attribute as Extbase;
use TYPO3\CMS\Extbase\DomainObject\AbstractEntity;

final class Tea extends AbstractEntity
{
    #[Extbase\Validate(['validator' => 'NotEmpty'])]
    protected string $title = '';
}
