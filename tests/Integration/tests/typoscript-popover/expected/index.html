TypoScript options 

An option by its full path: stdWrap.parseFunc , and a property of the top-level object: page.includeJS .

An option name alone stays code, because the reference documents several options of that name: wrap .

A path the reference does not document stays code: lib.myContent.wrap .

An option of Extbase plugins, below the key of a plugin: plugin.tx_blog.persistence.storagePid .

An object type the reference documents by a headline only, as an older version of it does, links there without a description. Found by its anchor, where a content object that is also a GIFBUILDER object is the content object: IMAGE . Found by a page of its own: EMBOSS .

An object type the reference no longer documents stays code: FILE , and so does a word that is no object type: GET .

TypoScript that names neither: page = PAGE .

Documented as options of their own 

An object type the reference documents as an option of its own says what it does: USER , COA_INT , PAGEVIEW , PAGE . So does a function named alone: stdWrap , typolink .

A function whose anchor a property already had, and one written in mixed case: HTMLparser_tags , HTMLparser . A top-level object: config .

The object of page = PAGE is not the type: page . A name of several options stays code: wrap .

Named in angle brackets 

Where the code alone does not tell the option, a role names its confval as :confval: does, in this manual or another: current , config.tx_extbase . Any kind of option counts, not only TypoScript ones.

A key that starts with an underscore can name its confval too: _CSS_DEFAULT_STYLE .

A name the manual does not document is reported: wrap . A manual that cannot be reached is not: wrap .

TSconfig 

A TSconfig option by its full path: mod.web_list.itemsLimitSingleTable .

A TSconfig option whose anchor does not follow its path, found by the path it declares: options.pageTree.doktypesToShowInNewPageDragArea . The same with options.pageTree.doktypesToShowInNewPageDragArea .

An option with a placeholder in its path is found as the placeholder is written: mod.wizards.newContentElement.wizardItems.group.before , but not with a name in its place: mod.wizards.newContentElement.wizardItems.common.before .

TSconfig the reference does not document stays code: mod.web_list.noViewWithDokTypes .
